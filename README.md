# RA2Web Assets

Public mirror of the game resource bundle used by the RA2Web desktop package.

## Contents

- Release asset: `game-res.tar`
  - Contains only game assets under `game-res/`:
    - `ra2.mix`
    - `language.mix`
    - `multi.mix`
    - `Taunts/`
    - `music/`
    - `glsl.png`, `ra2ts_l.webm`, `manifest.json`
  - Does **not** contain source code, launcher configs, user data, replays, build logs, or credentials.

## Integrity

- SHA-256 of `game-res.tar` is published in `game-res.sha256` release asset and in the release notes.
